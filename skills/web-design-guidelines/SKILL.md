# Web Design Guidelines

> Use this skill when making visual UI decisions for pages, components, and interaction patterns.

## Preferences

- Choose a clear visual direction before implementing
- Avoid generic default typography and flat layouts
- Use motion only when it clarifies hierarchy or state

## Quick Reference

### Design Rules

```text
1. Keep layouts intentional on both desktop and mobile.
2. Define color variables instead of scattering raw values.
3. Use typography and spacing to create hierarchy before adding decoration.
```
