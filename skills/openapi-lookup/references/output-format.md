# 输出格式说明

默认文本输出包含:

- **方法 + 路径、摘要、说明、标签** — 接口基本信息
- **请求参数 (query/path)** — 名称、位置、是否必填、类型、描述
- **请求体 (requestBody)** — 已展开 `$ref` 的完整 schema,并在 properties 中标注 `required` 的字段
- **响应** — 各状态码及其 schema(`data` 内部结构已递归展开)

## `$ref` 展开规则

`$ref` 会被递归解析为完整结构;遇到循环引用时以 `{ "$circularRef": "类型名" }` 标记并停止。

## JSON 输出

使用 `--json` 参数时,输出为结构化 JSON,便于进一步程序化处理。
